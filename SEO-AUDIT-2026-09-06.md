# Shipp-Mates SEO and visualizer audit — September 6, 2026

## Scope and findings

Reviewed the live homepage and current default-branch source, plus all 48 existing HTML pages. Compared the visualizer against the current Show Me Epoxy implementation. This is a technical/content audit, not a Search Console ranking or Core Web Vitals report.

- Existing pages already have unique titles, descriptions, one H1 and canonical URLs. Static HTML links and referenced assets resolve in the checkout. Structured data parses successfully.
- Twelve service-area stubs intentionally use noindex,follow. Keep that until real local project details, relevant original copy and photographs justify indexing. Do not merely remove noindex from near-duplicate pages.
- No standalone visualizer existed. The colors page only selected swatches and requested project photos.
- Responsive logo srcsets contained duplicate 480w and 900w descriptors, and above-the-fold logos were lazy-loaded.
- Homepage H1 emphasized “Premier” instead of explaining epoxy/concrete services.
- Uniform sitemap lastmod values did not reflect subsequent edits. Removed them rather than claim unsupported modification dates.
- Some absolute chemical-proof copy remained despite the previous content cleanup.

## Implemented

- Added floor-visualizer.html with the latest Show Me renderer, broad lighting, perspective flake, floor-edge reflections, upload resizing, adjustable mask, comparison slider, favorites and share links.
- Mapped all 25 colors directly to Shipp-Mates' existing catalog assets; Lake Ozark and Comet retain their actual catalog names. The default garage is explicitly labeled a sample. Other room/finish presets remain disabled until suitable assets exist, as in the reference implementation.
- Replaced branding, phone, business links, service routes and CRM endpoint with Shipp-Mates values. The visualizer includes selected color in quote submissions and preserves it in the instant calculator request. Photo files stay local to the visitor's browser.
- Visualizer submission now checks HTTP success and retains the form on errors rather than showing false success.
- Added navigation and color-page entry points plus sitemap inclusion.
- Improved homepage H1; fixed duplicate logo descriptors and above-fold loading; replaced remaining chemical-proof wording.
- Added Netlify /index.html → / permanent redirect to consolidate the duplicate homepage URL. Existing canonical URLs already point to /.

## Validation

49 HTML pages after additions: no duplicate titles or descriptions; one H1 and canonical each; JSON-LD parses; referenced static HTML assets and destinations exist. Sitemap has 37 entries, leaving 12 intentional noindex pages out. All 51 executable inline scripts parse. Ten Node regression tests pass, including catalog parity and failed quote handling.

Browser interaction testing, real CRM delivery, Google indexing, field performance and production redirect behavior have not been verified. No test leads were sent. Changes are prepared on a feature branch for review, not production.
